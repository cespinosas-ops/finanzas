# Finanzas

App web instalable de finanzas personales: gastos por categoría, presupuesto, tarjeta de crédito, meta de ahorro y cartola del mes. Los datos viven en Supabase detrás de login; este repositorio solo tiene la interfaz.

Para instalarla en el iPhone: abre la página en Safari, toca Compartir y luego "Agregar a pantalla de inicio".

Para verla con datos de prueba: agrega `?demo=1` al final de la dirección.
